# Coffee Shop Accountant ☕

نظام محاسبي وإداري مخصص للكافيتريا (Coffee Shops)، يساعد في إدارة المبيعات والمخزون وحسابات المالك.

## 🌟 مميزات البرنامج (Features)
* ادارة المبيعات: تسجيل المبيعات اليومية.
* إدارة المصاريف: تسجيل المصارف البومية.
* إدارة الحسابات: فصل إيرادات الكافيتريا عن مصاريف المالك.
* تقارير المبيعات: تقارير شاملة لمعرفة الأكثر مبيعاً والأرباح الصافية.

## 🛠️ التقنيات المستخدمة (Technologies)
* اللغة: Python
* واجهة المستخدم: Tkinter
* قاعدة البيانات: SQLite3
* التحويل لملف تنفيذي: PyInstaller
